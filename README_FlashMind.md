# 📚 FlashMind 

В рамках данного проекта был разработан интерактивный веб-сайт FlashMind, предназначенный для обучения с помощью карточек и автоматической генерации тестов.

---

## 🧠 Аннотация

Сайт по функционалу похож на платформу Quizlet, но расширен возможностями **искусственного интеллекта**, что позволяет адаптировать образовательный контент под каждого пользователя.

---

### 🎯 Цель проекта

Создание доступной и адаптивной образовательной среды, использующей технологии ИИ для:
- закрепления учебного материала;
- персонализации сложности;
- повышения вовлечённости учащихся.

---

### 🛠 Технологии

- **Языки**: HTML, JavaScript
- **Редакторы разработки**: VS Code, PyCharm
- **AI-интеграция**: OpenRouter.ai (API), ChatGPT
- **Хостинг**: GitHub Pages (frontend), Cloudflare Workers (secure backend для API-ключей)

---

### ⚙️ Функциональные особенности

- **🧩 Генерация тестов ИИ**  
  Модель искусственного интеллекта анализирует тему и формирует JSON-тесты с пояснениями.

- **📚 Разделение по предметам**  
  Карточки и тесты сгруппированы по дисциплинам:
  - Английский язык
  - Математика
  - География
  - Физика

- **🎚 Выбор уровня сложности**  
  Пользователь может фильтровать карточки по уровням: Beginner / Intermediate / Advanced

- **🌗 Смена темы интерфейса**  
  Реализована тёмная и светлая темы (переключаются вручную)

- **📂 Импорт / экспорт данных**  
  Поддержка загрузки и сохранения карточек в формате JSON

---

### 🤖 ИИ как образовательный помощник

Проект демонстрирует практическое применение нейросетевых моделей в сфере образования: генерация контента на лету, персонализация, пояснение ответов и формирование самостоятельных заданий.  
Это подчёркивает потенциал ИИ как **помощника в самообразовании**.

⚠️ Генерация тестов может занять некоторое время из-за загрузки нейросетевого сервиса — пожалуйста, дождитесь окончания обработки.

## 🔍 Подробное описание интерфейса и функций

### 📘 1. Карточки (Flashcards)
- Отображаются в виде переворачивающихся карточек (с фронта — вопрос, с обратной стороны — ответ).
- Каждая карточка содержит:
  - Вопрос
  - Изображение
  - Уровень сложности
- Кнопка ✔️ «I know» отмечает карточку как изученную.

### 📊 2. Прогресс
- Под карточками отображается индикатор прогресса (Progress bar).
- Когда пользователь изучил все карточки в теме:
  - Открывается модальное окно с поздравлением.
  - Доступна кнопка "Reset progress".

### 🎛 3. Фильтры
- Левая панель позволяет выбрать:
  - Предмет (English, Math, Geography, Physics)
  - Тему (например, Animals, Geometry)
  - Уровень сложности (Beginner, Intermediate, Advanced)

### 🌘 4. Переключение тем оформления
- Кнопка 🌙 в заголовке переключает между светлой и тёмной темами.
- Выбранная тема сохраняется в `localStorage`.

### 🧩 5. Генерация AI‑тестов
- Кнопка "🧩 Generate Quiz" открывает боковую панель и генерирует тест из 5 вопросов с вариантами.
- Каждый вопрос:
  - Содержит 4 варианта ответов
  - Показывает объяснение после ответа

### 📂 6. Импорт и экспорт данных
- Можно загрузить свои карточки через JSON (пример формата встроен).
- Возможность экспорта текущих карточек в файл `flashcards.json`.

## 📦 Структура проекта

- `index.html` — основной файл с интерфейсом и логикой
- AI-запросы отправляются через защищённый Cloudflare Worker
- Данные обрабатываются прямо в браузере без серверов
